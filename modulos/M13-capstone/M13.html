B1 · Release contract, escopo e orçamento de evidência

IDs M13-B01-C01..05 · Depende de M01 (workflow de evidência) e M04 (design docs) · Evidência: evidence/m13/B01/ · Artefatos: lab/docs/release-contract.md, lab/docs/risk-register.md

Problema e modelo mental

Release começa antes de código: quem sofre o problema, o que será medido e quanto pode custar. Se uma claim não tem método de medição definido antes de observar o resultado, ela vira publicidade. O release contract é um documento congelado que transforma intenção em hipótese testável; o risk register transforma os "e se" em linhas com dono, severidade e estado. O invariante é simples: nenhuma meta pode ser relaxada silenciosamente depois do teste — mudança de meta exige edição datada e motivo.

Decisão e trade-offs

Congelar cedo demais bloqueia aprendizado; congelar tarde demais permite mover o alvo para onde a flecha caiu. A decisão do Cartógrafo: congelar persona, três jornadas, claims, orçamento e go/no-go no início de cada épico; revisitar somente com edição registrada. Isso replica o que PRRs de SRE fazem com lançamentos (SRC-M13-11) sem peso institucional.

  3. O que diferencia um BLOCKED honesto de uma trilha simulada?

B3 · Ingestão segura e job assíncrono idempotente

IDs M13-B03-C01..05 · Depende de M03, LT01, LT02, M12 · Evidência: evidence/m13/B03/ · Artefato: lab/src/capstone_lab/ingest.py

Problema e modelo mental

Ingerir um repositório pode levar minutos; uma request HTTP não pode segurar o usuário esse tempo. O padrão: a request cria um job e devolve um id; o trabalho roda em outro contexto e o cliente consulta o estado (polling). Três requisitos não negociáveis: idempotência (repetir não duplica efeito), cancelamento cooperativo (o job verifica um flag entre unidades de trabalho) e retomada (crash no meio não força recomeço nem deixa estado impossível de reconciliar).

Mecanismo implementado

  • SnapshotStore: conteúdo endereçado por SHA-256; o mesmo arquivo ingerido duas vezes grava no mesmo path — idempotência estrutural, com escrita atômica (tmp+rename).
  • JobStore: estado persistido em JSON; submit com a mesma idempotency_key devolve o job existente.
  • Worker: checkpoint após cada arquivo em processed; recover_interrupted devolve jobs running a queued após crash; retry explícito limpa cancelamento anterior.
  • Políticas: ignore de .git/.env*/ __pycache__, skip de binário (byte nulo) e de arquivo acima de 1 MB, limite total de arquivos. Segredo, nunca vai para o snapshot.

Diagnóstico
  • snapshot duplicado após retry → chave de idempotência ausente ou não persistida;
  • job preso em running após crash → rodar recover_interrupted;
  • cancel não surte efeito → flag lido só no início, não entre arquivos;
  • secret no snapshot → ignore rules vazadas; teste B3 reprova até corrigir.

  3. O que muda quando o worker passa de 1 processo para N processos?

B4 · Parsing multi-language com corpus dourado

IDs M13-B04-C01..06 · Depende de M02, M10, M11 · Evidência: evidence/m13/B04/ · Artefatos: lab/src/capstone_lab/parsers.py, lab/fixtures/golden/

Problema e modelo mental

O Cartógrafo não entrega parsing ao LLM: símbolos e relações são determinísticos. A porta LanguageParser (Protocol) define o contrato — language_id e parse(path, source) -> ParseResult com símbolos, relações e erros medidos. Qualquer linguagem entra por um adapter que satisfaz a porta; o domínio nunca importa tipos do parser concreto.

Duas implementações neste Tier

  1. PythonAstParser: usa o módulo ast da stdlib (a gramática oficial do interpretador) para funções, classes, imports e chamadas; SyntaxError vira ParseError com linha, nunca exceção solta nem lista vazia silenciosa.
  2. MiniLangParser: segunda linguagem via regex derivadas de uma gramática EBNF local e versionada (func_decl, call_stmt, let_stmt). Limitação declarada: sem blocos/aninhamento; linha inválida é erro contado e o restante do arquivo continua analisável.
Tree-sitter — BLOCKED (causa registrada)

A especificação mira Tree-sitter com gramáticas nativas; binários/gramáticas não estão disponíveis neste ambiente. A porta já aceita um adapter Tree-sitter sem mudar o contrato; o suporte multi-language aqui é provado pelo par AST+MiniLang e pelo corpus dourado, com a limitação explicitada (risco R-02). Nenhuma saída de Tree-sitter foi simulada.

Corpus dourado e execução

Quatro fixtures formam o contrato: sample.py (4 símbolos, 7 relações), sample.mini (2 símbolos, 3 relações), broken.py (1 erro medido) e broken.mini (1 erro medido, restante preservado). O oráculo compara parse e golden campo a campo; divergência reprova:

... 8 passed (2 implementações, 4 fixtures dourados, erro medido, budget de erro do corpus)

Saída completa: evidence/m13/B04/pytest-parsers.txt. O teste test_error_budget_of_corpus_is_measured fixa em 2 os arquivos com erro do corpus — erro de parse é número auditável, não ruído varrido.

Diagnóstico
  • golden diverge após mudança intencional do parser → regenerar e revisar o diff;
  • SyntaxError tratada como silêncio → viola o contrato; erro precisa ir ao ParseResult;
  • nova linguagem sem fixture dourada → não conta como suporte (aceitação do B4);
  • confundir MiniLang com linguagem real → ler a gramática e as limitações declaradas.

Checkpoint

  2. O que o corpus dourado prova que um teste de "não quebra" não prova?
  3. Quais passos levariam um adapter Tree-sitter a PASS sem alterar o contrato?

B5 · Modelo de dados, migrations e isolamento

IDs M13-B05-C01..05 · Depende de M03, M07, M10, M12 · Evidência: evidence/m13/B05/ · Artefatos: lab/src/capstone_lab/db.py, lab/docs/migrations-design.md

Problema e modelo mental

Multi-tenant falha por vazamento sutil: uma query sem filtro de tenant expõe tudo. O modelo local usa SQLite com PRAGMA foreign_keys = ON, tabelas tenant → repository → snapshot → file → symbol/edge e job/usage_event, todas as linhas de cliente carregando tenant_id. Migrations são pares versionados (up/down) aplicados em transação por passo e registrados em schema_migrations; rollback é operação suportada.

Decisão e fronteira PG/RLS

Nesta camada, isolamento é scoping obrigatório: toda função pública de leitura exige tenant_id. O Postgres/RLS (WITH CHECK, políticas por sessão, pool com SET LOCAL) é defesa em profundidade que entra no adapter PG — design completo e SQL de política em docs/migrations-design.md. Postgres fica BLOCKED ambiental neste lote (mesmo risco R-01/R-03 do Docker); o que está provado é limitado ao que o SQLite realmente garante, e o documento separa explicitamente o provado do planejado.

B6 · Retrieval híbrido com ACL, citação e abstenção

IDs M13-B06-C01..06 · Depende de B5 (escopo de tenant) e M08 (RAG) · Evidência: evidence/m13/B06/ · Artefato: lab/src/capstone_lab/retrieval.py

Problema e modelo mental

Busca que vaza dado de outro tenant ou inventa resposta quando o índice não cobre a pergunta destrói o produto. Três invariantes: ACL antes de recuperar (o filtro de tenant acontece antes de pontuar qualquer chunk, não depois); score híbrido = alpha · BM25 + (1-alpha) · cosseno tf, combinando sinal lexical exato com similaridade distribuída sem depender de embeddings externos; abstenção: melhor score abaixo do limiar → lista vazia ("não sei"), nunca um palpite reranqueado. Todo hit carrega path e line (citação), resposta sem fonte não existe.

Avaliação como oráculo

O dataset de retrieval (fixtures/retrieval/dataset_v1.json) é versionado e pré-registra limiares de Recall@k e MRR; evaluate mede, meets_thresholds devolve violações. Regressão de qualidade reprova o teste test_dataset_meets_preregistered_recall_and_mrr — a claim de qualidade tem método antes do número.

lab/src/capstone_lab/retrieval.py (cópia exata, conferida por diff):

"""Busca híbrida (lexical BM25 + vetorial-lite tf-idf) com ACL e abstenção (M13 B6).

Invariantes:
- ACL **antes** de recuperar: o índice filtra por ``tenant_id`` antes de pontuar;
  nenhum chunk de outro tenant entra no espaço de busca (zero vazamento).
- Threshold de abstenção: se o melhor score ficar abaixo do limiar, a resposta
  é "não sei" (lista vazia), nunca um palpite reranqueado.
- Dataset de retrieval versionado (``fixtures/retrieval/dataset_v1.json``)
  registra queries, chunks e os limiares Recall@k/MRR exigidos; a avaliação é
  um oráculo, não uma amostra.
"""

from __future__ import annotations

import json
import math
import re
from collections import Counter
from dataclasses import dataclass
from pathlib import Path
from typing import Any

_TOKEN = re.compile(r"[a-zà-ú0-9_]+")
BM25_K1 = 1.5
BM25_B = 0.75


@dataclass(frozen=True)
class Chunk:
    chunk_id: str
    tenant_id: str
    path: str
    line: int
    text: str


@dataclass(frozen=True)
class Hit:
    chunk_id: str
    path: str
    line: int
    score: float
    snippet: str


def tokenize(text: str) -> list[str]:
    return _TOKEN.findall(text.lower())


def _cosine_tf(q: Counter[str], d: Counter[str]) -> float:
    if not q or not d:
        return 0.0
    inter = sum(min(q[t], d[t]) for t in q.keys() & d.keys())
    nq = math.sqrt(sum(v * v for v in q.values()))
    nd = math.sqrt(sum(v * v for v in d.values()))
    return inter / (nq * nd) if nq and nd else 0.0


class HybridIndex:
    """Índice híbrido em memória; escopo de tenant aplicado antes do scoring."""

    def __init__(self, alpha: float = 0.5) -> None:
        if not 0.0 <= alpha <= 1.0:
            raise ValueError("alpha deve estar em [0, 1]")
        self.alpha = alpha
        self._chunks: list[Chunk] = []
        self._tf: list[Counter[str]] = []
        self._df: Counter[str] = Counter()
        self._total_len = 0

    def add(self, chunk: Chunk) -> None:
        tf = Counter(tokenize(chunk.text))
        self._chunks.append(chunk)
        self._tf.append(tf)
        self._total_len += sum(tf.values())
        for term in tf:
            self._df[term] += 1

    def _bm25(self, q_tf: Counter[str], i: int, n_docs: int) -> float:
        d_tf = self._tf[i]
        d_len = sum(d_tf.values()) or 1
        avg = (self._total_len / max(len(self._chunks), 1)) or 1.0
        score = 0.0
        for term, qf in q_tf.items():
            tf = d_tf.get(term, 0)
            if tf == 0:
                continue
            idf = math.log(1 + (n_docs - self._df[term] + 0.5) / (self._df[term] + 0.5))
            denom = tf + BM25_K1 * (1 - BM25_B + BM25_B * d_len / avg)
            score += idf * (tf * (BM25_K1 + 1) / denom) * qf
        return score

    def search(self, tenant_id: str, query: str, top_k: int, threshold: float) -> list[Hit]:
        """ACL antes de recuperar: só chunk do tenant participa do scoring."""
        q_tf = Counter(tokenize(query))
        if not q_tf:
            return []
        scoped = [i for i, c in enumerate(self._chunks) if c.tenant_id == tenant_id]
        scored: list[tuple[float, int]] = []
        for i in scoped:
            bm = self._bm25(q_tf, i, max(len(scoped), 1))
            vec = _cosine_tf(q_tf, self._tf[i])
            scored.append((self.alpha * bm + (1 - self.alpha) * vec, i))
        scored.sort(key=lambda p: (p[0], self._chunks[p[1]].chunk_id), reverse=True)
        hits = [
            Hit(
                chunk_id=(c := self._chunks[i]).chunk_id,
                path=c.path,
                line=c.line,
                score=round(s, 6),
                snippet=c.text[:120],
            )
            for s, i in scored
            if s > 0.0
        ][:top_k]
        if not hits or hits[0].score < threshold:
            return []  # abstenção: melhor score abaixo do limiar
        return hits


def load_dataset(path: Path) -> dict[str, Any]:
    data: dict[str, Any] = json.loads(path.read_text(encoding="utf-8"))
    for key in ("version", "chunks", "queries", "thresholds"):
        if key not in data:
            raise ValueError(f"dataset sem campo obrigatório: {key}")
    return data


def evaluate(index: HybridIndex, dataset: dict[str, Any], top_k: int) -> dict[str, float]:
    """Recall@k e MRR sobre o dataset versionado; zero consultas -> erro."""
    queries = dataset["queries"]
    if not queries:
        raise ValueError("dataset sem queries")
    recall_sum, mrr_sum = 0.0, 0.0
    for q in queries:
        relevant = set(q["relevant"])
        hits = index.search(q["tenant_id"], q["q"], top_k=top_k, threshold=q["threshold"])
        got = [h.chunk_id for h in hits]
        recall_sum += len(relevant & set(got)) / len(relevant)
        mrr_sum += next((1.0 / (rank + 1) for rank, cid in enumerate(got) if cid in relevant), 0.0)
    return {"recall_at_k": recall_sum / len(queries), "mrr": mrr_sum / len(queries)}


def meets_thresholds(metrics: dict[str, float], thresholds: dict[str, float]) -> list[str]:
    """Retorna violações; lista vazia = limiar pré-registrado atingido."""
    return [
        f"{name}: {metrics.get(name, 0.0):.3f} < {floor:.3f}"
        for name, floor in thresholds.items()
        if metrics.get(name, 0.0) < floor
    ]
Diagnóstico
  • hit de outro tenant → filtro aplicado depois do scoring (violação de invariante);
  • resposta sem path:line → citação dropada no caminho do retorno;
  • "funcionou no meu teste" sem Recall/MRR → qualidade sem oráculo é opinião;
  • limiar relaxado após falha → pré-registro rasgado; editing datado ou NO-GO.

Checkpoint

  1. Por que o escopo de tenant precisa ocorrer antes, e não depois, do scoring?

"""Grafo de entidades/relações com proveniência e update incremental (M13 B7).

Invariantes:
- Toda aresta carrega proveniência (arquivo+linha de origem) e origem
  ``extracted`` (fato do parser) ou ``inferred`` (inferência, rotulada).
- Update incremental: re-processar um arquivo substitui apenas as arestas
  emitidas por esse arquivo; o restante do grafo é preservado.
- As consultas estruturais (quem chama, quem importa, métricas de grau)
  respondem o que busca textual isolada não responde.
"""

from __future__ import annotations

import json
from collections import Counter
from dataclasses import asdict, dataclass
from pathlib import Path
from typing import Any

from capstone_lab.parsers import ParseResult


@dataclass(frozen=True)
class Provenance:
    source: str  # "extracted" (fato do parser) | "inferred" (inferência rotulada)
    path: str
    line: int


@dataclass(frozen=True)
class Edge:
    src: str
    dst: str
    kind: str  # "calls" | "imports" | ...
    provenance: Provenance


class CodeGraph:
    def __init__(self) -> None:
        self._edges: list[Edge] = []

    def add_file(self, result: ParseResult, source: str = "extracted") -> None:
        """Update incremental: arestas do arquivo são substituídas, não duplicadas."""
        self._edges = [e for e in self._edges if e.provenance.path != result.path]
        for rel in result.relations:
            self._edges.append(
                Edge(result.path, rel.target, rel.kind, Provenance(source, result.path, rel.line))
            )

    def add_inferred(self, src: str, dst: str, kind: str, path: str, line: int) -> None:
        self._edges.append(Edge(src, dst, kind, Provenance("inferred", path, line)))

    def callers_of(self, name: str) -> list[Edge]:
        return sorted(
            (e for e in self._edges if e.kind == "calls" and e.dst == name),
            key=lambda e: (e.provenance.path, e.provenance.line),
        )

    def imports_of(self, path: str) -> list[Edge]:
        return [e for e in self._edges if e.kind == "imports" and e.src == path]

    def in_degree(self, name: str) -> int:
        return sum(1 for e in self._edges if e.dst == name)

    def top_by_in_degree(self, top: int) -> list[tuple[str, int]]:
        return Counter(e.dst for e in self._edges).most_common(top)

    def facts_vs_inferred(self) -> dict[str, int]:
        out = {"extracted": 0, "inferred": 0}
        for e in self._edges:
            out[e.provenance.source] += 1
        return out

    def without_provenance(self) -> list[Edge]:
        return [
            e
            for e in self._edges
            if not e.provenance.path or e.provenance.line <= 0 or not e.provenance.source
        ]

    def golden_diff(self, golden_path: Path) -> list[str]:
        """Compara o grafo com o corpus dourado; lista vazia = conformidade total."""
        expected = json.loads(golden_path.read_text(encoding="utf-8"))
        actual: dict[str, Any] = {
            "callers": {
                name: [{"path": e.src, "line": e.provenance.line} for e in self.callers_of(name)]
                for name in expected.get("callers", {})
            },
            "facts_vs_inferred": self.facts_vs_inferred(),
        }
        diffs: list[str] = []
        for key, want in expected.items():
            if key not in actual:
                continue  # metadados do golden (ex.: description)
            if actual[key] != want:
                diffs.append(f"campo '{key}' diverge do corpus dourado")
        return diffs


def edges_as_dicts(graph: CodeGraph) -> list[dict[str, Any]]:
    return [asdict(e) for e in graph._edges]

"""Gateway de modelos: porta, fake local e normalizações (M13 B8).

Invariantes:
- O domínio depende apenas da porta ``ModelGateway`` e dos tipos internos
  (``ModelRequest``/``ModelResponse``/``NormalizedError``); nenhum SDK
  proprietário aparece fora de um adapter.
- Erros de qualquer adapter são normalizados para ``ErrorKind`` fechado;
  ``usage`` (tokens/custo) segue o mesmo formato em todos.
- Adapters reais (OpenAI/Anthropic/locais via rede) ficam BLOCKED neste
  ambiente (sem rede/credenciais) — ver RASTREABILIDADE; nada é simulado
  como se fosse chamada real.
"""

from __future__ import annotations

import json
import time
from collections.abc import Callable
from dataclasses import dataclass
from enum import StrEnum
from typing import Any, Protocol


class ErrorKind(StrEnum):
    TIMEOUT = "timeout"
    RATE_LIMIT = "rate_limit"
    INVALID_OUTPUT = "invalid_output"
    BUDGET_EXCEEDED = "budget_exceeded"
    UNAVAILABLE = "unavailable"


@dataclass(frozen=True)
class Usage:
    input_tokens: int
    output_tokens: int
    cost_usd: float


@dataclass(frozen=True)
class ModelRequest:
    prompt: str
    schema: dict[str, Any] | None = None  # structured output (JSON Schema)
    timeout_s: float = 5.0
    max_retries: int = 2


@dataclass(frozen=True)
class ModelResponse:
    content: str
    usage: Usage
    structured: dict[str, Any] | None = None


@dataclass(frozen=True)
class NormalizedError(Exception):
    kind: ErrorKind
    provider: str
    detail: str


class ModelGateway(Protocol):
    name: str

    def complete(self, request: ModelRequest) -> ModelResponse: ...


class FakeModelAdapter:
    """Adapter determinístico para testes: respostas declaradas por prompt.

    Declarado explicitamente como FAKE: nenhuma chamada sai do processo.
    """

    name = "fake"

    def __init__(self, script: dict[str, str] | None = None, latency_s: float = 0.0) -> None:
        self._script = script or {}
        self._latency = latency_s
        self.calls: list[str] = []

    def complete(self, request: ModelRequest) -> ModelResponse:
        start = time.monotonic()
        self.calls.append(request.prompt)
        content = self._script.get(request.prompt, "")
        if self._latency > request.timeout_s:
            raise NormalizedError(ErrorKind.TIMEOUT, self.name, "latência simulada > timeout")
        structured = None
        if request.schema is not None:
            try:
                structured = json.loads(content)
            except json.JSONDecodeError as exc:
                raise NormalizedError(
                    ErrorKind.INVALID_OUTPUT, self.name, f"JSON inválido: {exc}"
                ) from exc
        _ = time.monotonic() - start  # medido, não simulado por sleep
        tokens = len(content.split()) + len(request.prompt.split())
        return ModelResponse(
            content=content, usage=Usage(tokens, tokens, tokens * 0.0), structured=structured
        )


def with_retry_budget(
    gateway: ModelGateway, retryable: frozenset[ErrorKind]
) -> Callable[[ModelRequest], ModelResponse]:
    """Envolve o gateway com retry limitado a ``max_retries`` em erros retryable."""

    def call(request: ModelRequest) -> ModelResponse:
        attempts = request.max_retries + 1
        last: NormalizedError | None = None
        for _ in range(attempts):
            try:
                return gateway.complete(request)
            except NormalizedError as exc:
                last = exc
                if exc.kind not in retryable:
                    raise
        assert last is not None
        raise NormalizedError(
            ErrorKind.BUDGET_EXCEEDED,
            last.provider,
            f"retry budget esgotado após {attempts} tentativas",
        )

    return call
Diagnóstico
  • exceção de SDK subindo ao domínio → normalização ausente no adapter;
  • retry loop infinito em erro não-retryable → budget/kind não conferidos;
  • usage divergente entre adapters → formato não normalizado na porta;
  • "testado contra o modelo X" sem credencial → BLOCKED honesto, nunca PASS.

"""Agente com estado tipado, budget, stop, checkpoint e retomada (M13 B9).

Invariantes:
- Estado tipado (``AgentState``) é serializável a JSON; checkpoint permite
  retomar após kill sem repetir tool já concluída (efeito idempotente).
- Sem LLM real neste ambiente: a política de decisão é o
  ``ScriptedPlanner`` — determinístico, explicitamente ROTULADO como simulado
  localmente (``planner_label``). O trace registra cada passo real executado.
- Nenhum ``sleep()`` e nenhuma resposta hardcoded contam como "execução":
  cada passo roda uma tool real deste pacote (busca/grafo) e grava o resultado.
"""

from __future__ import annotations

import json
from collections.abc import Callable
from dataclasses import asdict, dataclass, field
from pathlib import Path
from typing import Any, Protocol

from capstone_lab.graph import CodeGraph
from capstone_lab.retrieval import HybridIndex

ToolFn = Callable[[str], str]


@dataclass
class AgentState:
    goal: str
    planner_label: str  # ex.: "scripted-simulated (sem LLM real)"
    plan: list[str] = field(default_factory=list)
    done: int = 0
    results: dict[str, str] = field(default_factory=dict)
    status: str = "running"  # running | done | budget_exceeded | stopped
    trace: list[dict[str, Any]] = field(default_factory=list)


class Planner(Protocol):
    label: str

    def next_step(self, state: AgentState) -> str | None: ...


class ScriptedPlanner:
    """Política determinística: executa o plano declarado na ordem.

    Rotulado: NÃO é um LLM; decide por script local para provar os
    mecanismos de estado/budget/checkpoint neste Tier.
    """

    label = "scripted-simulated (sem LLM real)"

    def __init__(self, steps: list[str]) -> None:
        self._steps = steps

    def next_step(self, state: AgentState) -> str | None:
        if state.done >= len(self._steps):
            return None
        return self._steps[state.done]


def default_tools(index: HybridIndex, graph: CodeGraph, tenant: str) -> dict[str, ToolFn]:
    def search_tool(query: str) -> str:
        hits = index.search(tenant, query, top_k=3, threshold=0.0)
        return json.dumps([h.chunk_id for h in hits])

    def callers_tool(name: str) -> str:
        edges = graph.callers_of(name)
        return json.dumps([f"{e.src}:{e.provenance.line}" for e in edges])

    return {"search": search_tool, "callers": callers_tool}


class AgentRunner:
    """Executa o plano passo a passo com budget, stop e checkpoint JSON.

    Passo: ``"tool_name:argumento"``. Cada passo concluído grava resultado em
    ``state.results[step]``; reexecutar um passo já concluído é impossível —
    o runner retoma a partir de ``state.done``.
    """

    def __init__(self, tools: dict[str, ToolFn], max_steps: int) -> None:
        if max_steps <= 0:
            raise ValueError("budget de passos deve ser positivo")
        self._tools = tools
        self._budget = max_steps
        self.tool_invocations = 0

    def run(self, state: AgentState, planner: Planner) -> AgentState:
        spent = 0
        while state.status == "running":
            if state.done >= self._budget:
                state.status = "budget_exceeded"
                break
            step = planner.next_step(state)
            if step is None:
                state.status = "done"
                break
            name, _, arg = step.partition(":")
            tool = self._tools.get(name)
            if tool is None:
                raise KeyError(f"tool desconhecida: {name}")
            self.tool_invocations += 1
            spent += 1
            output = tool(arg)
            state.results[step] = output
            state.trace.append(
                {
                    "step": state.done,
                    "tool": name,
                    "arg": arg,
                    "output": output,
                    "planner": planner.label,
                }
            )
            state.done += 1
            if planner.next_step(state) is None:
                state.status = "done"
            _ = spent
        return state

    def checkpoint(self, state: AgentState, path: Path) -> None:
        tmp = path.with_suffix(path.suffix + ".tmp")
        tmp.write_text(json.dumps(asdict(state), ensure_ascii=False), encoding="utf-8")
        tmp.replace(path)  # escrita atômica

    def resume(self, path: Path, planner: Planner) -> AgentState:
        data = json.loads(path.read_text(encoding="utf-8"))
        state = AgentState(**data)
        if state.status in {"budget_exceeded"}:
            state.status = "running"  # budget novo: retomada a partir de state.done
        return self.run(state, planner)
Diagnóstico

  • run infinito → ausência de budget (ou budget ≤ 0 aceito);
  • trace sem planner label → simulado circulando como se fosse LLM;
  • tool desconhecida ignorada → falha silenciosa; o contrato exige erro alto.

def encode_frame(message: dict[str, Any]) -> bytes:
    body = json.dumps(message, ensure_ascii=False).encode("utf-8")
    return f"Content-Length: {len(body)}\r\n\r\n".encode() + body


def decode_frames(buffer: bytes) -> tuple[list[dict[str, Any]], bytes]:
    """Extrai mensagens completas; devolve também o restante não processado."""
    messages: list[dict[str, Any]] = []
    while (sep := buffer.find(b"\r\n\r\n")) != -1:
        header, rest = buffer[:sep].decode(), buffer[sep + 4 :]
        length = int(header.split(":", 1)[1].strip())
        if len(rest) < length:
            break
        messages.append(json.loads(rest[:length]))
        buffer = rest[length:]
    return messages, buffer


class McpServer:
    """Servidor MCP mínimo em processo: initialize, tools/list, tools/call."""

    def __init__(self, tools: dict[str, Callable[[dict[str, Any]], Any]]) -> None:
        self._tools = tools
        self.initialized = False

    def handle(self, request: dict[str, Any]) -> dict[str, Any]:
        rid = request.get("id")
        if request.get("jsonrpc") != "2.0":
            return {
                "jsonrpc": "2.0",
                "id": rid,

            }
        method = request.get("method")
        if method == "initialize":
            self.initialized = True
            return {
                "jsonrpc": "2.0",
                "id": rid,
                "result": {"protocolVersion": "2025-06-18", "capabilities": {"tools": {}}},
            }
        if method == "tools/list":
            return {
                "jsonrpc": "2.0",
                "id": rid,

                    "jsonrpc": "2.0",
                    "id": rid,

            return {
                "jsonrpc": "2.0",
                "id": rid,
                "result": {"content": [{"type": "text", "text": json.dumps(result)}]},
            }

            "jsonrpc": "2.0",
            "id": rid,
            "error": {"code": -32601, "message": "method not found"},

"""Evals versionados e quality gate de regressão (M13 B11).

Invariantes:
- Datasets são **dado versionado** (``fixtures/evals/*.json``), com ``name``,
  ``version`` e ``kind`` em {golden, out_of_scope, injection}; carregar um
  arquivo fora do esquema é erro, não warning.
- O veredito do relatório é **derivado das métricas**, nunca lido de flags do
  JSON: ``passed``/``approved`` no arquivo são ignorados pelo gate.
- Regressão = queda de métrica além do budget em relação a um baseline
  versionado; o gate retorna a lista de violações (vazia = PASS) para o CI
  falhar com causa explícita.
- Sem juiz de LLM: o "juiz" aqui é uma rubrica determinística (função pura de
  métricas com pesos registrados), reproduzível em qualquer máquina.
"""

from __future__ import annotations

import json
from collections import Counter
from pathlib import Path
from typing import Any

from .retrieval import Chunk, HybridIndex, tokenize

KINDS = ("golden", "out_of_scope", "injection")
REQUIRED_FIELDS = ("name", "version", "kind", "chunks", "cases")
ANSWER_FLOOR = 0.5  # F1 mínimo pré-registrado para o golden path
REGRESSION_BUDGET = 0.05  # queda máxima tolerada por métrica vs. baseline


def load_evalset(path: Path) -> dict[str, Any]:
    """Carrega dataset versionado; valida esquema mínimo e kind declarado."""
    data: dict[str, Any] = json.loads(path.read_text(encoding="utf-8"))
    for key in REQUIRED_FIELDS:
        if key not in data:
            raise ValueError(f"dataset sem campo obrigatório: {key}")
    if data["kind"] not in KINDS:
        raise ValueError(f"kind desconhecido: {data['kind']}")
    if not data["cases"]:
        raise ValueError("dataset sem casos")
    return data


def token_f1(prediction: str, reference: str) -> float:
    """F1 de tokens (multiconjunto); 1.0 só quando as contagens coincidem."""
    p, r = Counter(tokenize(prediction)), Counter(tokenize(reference))
    if not p or not r:
        return 1.0 if p == r else 0.0
    common = sum((p & r).values())
    if common == 0:
        return 0.0
    precision, recall = common / sum(p.values()), common / sum(r.values())
    return round(2 * precision * recall / (precision + recall), 6)


def structural_score(answer: dict[str, Any]) -> float:
    """1.0 se a resposta tem a forma contratual: chaves e citações coerentes."""
    if set(answer) != {"answer", "abstained", "citations"}:
        return 0.0
    if answer["abstained"]:
        return 1.0 if (answer["answer"] is None and answer["citations"] == []) else 0.0
    return 1.0 if (isinstance(answer["answer"], str) and answer["citations"]) else 0.0


def build_index(chunks: list[dict[str, Any]]) -> HybridIndex:
    index = HybridIndex()
    for c in chunks:
        if c.get("poisoned"):
            continue  # controle de pipeline: conteúdo marcado não entra no índice
        index.add(Chunk(c["chunk_id"], c["tenant_id"], c["path"], c["line"], c["text"]))
    return index


def extractive_answer(index: HybridIndex, case: dict[str, Any]) -> dict[str, Any]:
    """Respondedor extrativo real (baseline): busca e cita; abstém-se sob limiar.

    Substituível por qualquer função ``case -> answer`` com o mesmo contrato;
    o que o gate mede é a saída, não a implementação.
    """
    hits = index.search(case["tenant_id"], case["q"], top_k=3, threshold=case["threshold"])
    if not hits:
        return {"answer": None, "abstained": True, "citations": []}
    return {
        "answer": hits[0].snippet,
        "abstained": False,
        "citations": [f"{h.path}:{h.line}" for h in hits],
    }


def run_eval(dataset: dict[str, Any]) -> dict[str, Any]:
    """Executa o dataset com o respondedor extrativo e deriva as métricas."""
    index = build_index(dataset["chunks"])
    kind = dataset["kind"]
    answers = [extractive_answer(index, c) for c in dataset["cases"]]
    metrics: dict[str, float] = {
        "structural": sum(structural_score(a) for a in answers) / len(answers)
    }
    if kind == "golden":
        metrics["answer_f1"] = round(
            sum(
                token_f1(str(a["answer"] or ""), c["reference"])
                for a, c in zip(answers, dataset["cases"], strict=True)
            )
            / len(answers),
            6,
        )
    elif kind == "out_of_scope":
        metrics["abstention_accuracy"] = sum(1.0 for a in answers if a["abstained"]) / len(answers)
    else:  # injection
        metrics["injection_resistance"] = sum(
            1.0
            for a, c in zip(answers, dataset["cases"], strict=True)
            if c["marker"] not in str(a["answer"] or "")
        ) / len(answers)
    return {
        "name": dataset["name"],
        "version": dataset["version"],
        "kind": kind,
        "n": len(answers),
        "metrics": metrics,
    }


def regression_gate(
    baseline: dict[str, Any], current: dict[str, Any], budget: float = REGRESSION_BUDGET
) -> list[str]:
    """Compara métricas homônimas; retorna violações (vazia = PASS).

    Campos como ``passed``/``approved`` presentes em qualquer dos relatórios
    são deliberadamente ignorados: o veredito é função das métricas.
    """
    if baseline["name"] != current["name"]:
        return [f"relatórios de datasets distintos: {baseline['name']} vs {current['name']}"]
    violations: list[str] = []
    for metric, base_value in baseline["metrics"].items():
        cur_value = current["metrics"].get(metric, 0.0)
        if cur_value < base_value - budget:
            violations.append(
                f"{baseline['name']}.{metric}: {cur_value:.3f} caiu de "
                f"{base_value:.3f} além do budget {budget}"
            )
    return violations

"""Metering, entitlement, quotas e reconciliação de webhooks (M13 B13).

Invariantes:
- O usage ledger é a única fonte de verdade de consumo; todo número publicado
  (custo, receita, margem) é **derivado** do ledger, nunca digitado.
- Idempotência em duas camadas: eventos de uso por ``idempotency_key`` e
  webhooks por ``id`` de evento; duplicado não altera o estado.
- Webhooks podem chegar duplicados e fora de ordem; a reconciliação ordena por
  ``(created, id)`` e converge para o mesmo saldo final.
- Stripe real/test-mode: BLOCKED ambiental (sem credenciais/rede); o provider
  aqui é um ``FakeProvider`` local explicitamente rotulado — ver RASTREABILIDADE.
"""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

PLANS: dict[str, dict[str, Any]] = {
    "free": {"quota_analyses": 10, "price_cents": 0, "features": ["search"]},
    "pro": {"quota_analyses": 500, "price_cents": 4900, "features": ["search", "agent", "api"]},
    "team": {
        "quota_analyses": 5000,
        "price_cents": 29900,
        "features": ["search", "agent", "api", "sso"],
    },
}
COST_PER_ANALYSIS_CENTS = 35  # custo unitário estimado registrado (exemplo local)


@dataclass(frozen=True)
class UsageEvent:
    tenant_id: str
    kind: str
    quantity: int
    idempotency_key: str


class UsageLedger:
    """Append-only com dedup por idempotency key; totais sempre derivados."""

    def __init__(self) -> None:
        self._events: dict[str, UsageEvent] = {}

    def record(self, event: UsageEvent) -> bool:
        """Registra; retorna False se a chave já existia (duplicado ignorado)."""
        if event.idempotency_key in self._events:
            return False
        self._events[event.idempotency_key] = event
        return True

    def total(self, tenant_id: str, kind: str) -> int:
        return sum(
            e.quantity for e in self._events.values() if e.tenant_id == tenant_id and e.kind == kind
        )

    def size(self) -> int:
        return len(self._events)


def entitled(plan: str, feature: str) -> bool:
    return feature in PLANS[plan]["features"]

class Metrics:
    """Contadores e histograma local com percentil exato sobre amostra real."""

    def __init__(self) -> None:
        self.counters: dict[str, int] = {}
        self.samples: dict[str, list[float]] = {}

    def inc(self, name: str, value: int = 1) -> None:
        self.counters[name] = self.counters.get(name, 0) + value

    def observe(self, name: str, value: float) -> None:
        self.samples.setdefault(name, []).append(value)

    def percentile(self, name: str, p: float) -> float:
        data = sorted(self.samples.get(name, []))
        if not data:

        return data[idx]


def error_rate(events: list[bool]) -> float:
    """Fração de erros; lista vazia é erro (sem dado ≠ 0% de erro)."""
    if not events:
        raise ValueError("sem eventos para calcular taxa")
    return sum(1 for ok in events if not ok) / len(events)


def burn_rate(events: list[bool], slo: float) -> float:
    """Burn rate = taxa de erro observada / taxa de erro orçamentada."""
    budget = 1.0 - slo
    if budget <= 0:
        raise ValueError("SLO deve ser < 1.0")
    return error_rate(events) / budget


def slo_alert(events: list[bool], slo: float, fast_burn: float = 2.0) -> str | None:

    rate = burn_rate(events, slo)
    if rate >= fast_burn:
        return f"ALERTA fast-burn: burn rate {rate:.2f}x >= {fast_burn}x do budget"
    return None

"""Performance, capacidade e modo local: benchmark real, percentis e estimativa (M13 B16).

Invariantes:
- Benchmark é **medição real**: ``time.perf_counter`` sobre amostras reais; os
  números publicados vêm da execução registrada em evidência, nunca digitados.
- Percentis (p50/p95/p99) são função pura das amostras — mesma entrada, mesma
  saída; saturação e capacity estimate são derivados por regra declarativa.
- A conclusão é válida **apenas** para o ambiente registrado (CPU/OS/Python);
  o relatório carrega o ambiente e proíbe extrapolação além da amostra.
- Modo local vs. cloud: aqui só existe o local; comparação real em cloud é
  BLOCKED ambiental. A regra de previsão de custo é modelada, não medida.
"""

from __future__ import annotations

import math
import platform
import statistics
import sys
import time
from collections.abc import Callable
from dataclasses import dataclass
from typing import Any


def percentil(samples: list[float], p: float) -> float:
    """Percentil por interpolação linear (método 'inclusive', tipo R-7)."""
    if not samples:
        raise ValueError("sem amostras")
    if not 0.0 < p <= 100.0:
        raise ValueError("p fora de (0, 100]")
    ordered = sorted(samples)
    if len(ordered) == 1:
        return ordered[0]
    rank = (p / 100.0) * (len(ordered) - 1)
    lo, hi = math.floor(rank), math.ceil(rank)
    if lo == hi:
        return ordered[lo]
    return ordered[lo] + (ordered[hi] - ordered[lo]) * (rank - lo)

    python: str
    platform: str
    machine: str


def ambient_atual() -> Ambiente:
    """Ambiente real da execução — obrigatório em todo relatório de benchmark."""
    return Ambiente(
        python=sys.version.split()[0],
        platform=platform.platform(),
        machine=platform.machine(),
    )


@dataclass(frozen=True)
class BenchmarkReport:
    name: str
    samples_ms: tuple[float, ...]
    ambiente: Ambiente
    rotulo: str = "medicao-real"  # nunca "simulado"; rótulo deixa explícito

    @property
    def p50(self) -> float:
        return percentil(list(self.samples_ms), 50.0)

    @property
    def p95(self) -> float:
        return percentil(list(self.samples_ms), 95.0)

    @property
    def p99(self) -> float:
        return percentil(list(self.samples_ms), 99.0)


def benchmark(fn: Callable[[], Any], *, samples: int = 15) -> BenchmarkReport:
    """Mede ``fn`` `samples` vezes com warm-up; mede de verdade, sem sleep fixo."""
    if samples < 5:
        raise ValueError("samples mínimo: 5")
    fn()  # warm-up, descartado
    medidas: list[float] = []
    for _ in range(samples):
        t0 = time.perf_counter()
        fn()
        medidas.append((time.perf_counter() - t0) * 1000.0)
    return BenchmarkReport(getattr(fn, "__name__", "fn"), tuple(medidas), ambient_atual())


def saturacao(throughputs: list[float], *, tolerancia: float = 0.05) -> int | None:
    """Índice da primeira amostra de saturação: ganho relativo < tolerância.

    Recebe throughput crescente de carga (ex.: ops/s por nível de concorrência);
    devolve o índice onde o sistema para de escalar, ou None se não saturou.
    """
    for i in range(1, len(throughputs)):
        base = throughputs[i - 1]
        if base <= 0:
            raise ValueError("throughput deve ser positivo")
        if (throughputs[i] - base) / base < tolerancia:
            return i
    return None

    capacidade_observada_s: float  # throughput na saturação (medido)

    def decisao(self) -> str:

        return "OK" if self.capacidade_observada_s >= alvo else "CAPACIDADE-INSUFICIENTE"

    if not reports:

    envs = {r.ambiente for r in reports}
    if len(envs) != 1:
        raise ValueError("relatórios de ambientes distintos não se misturam")

def throughput_curve(levels: list[int], fn: Callable[[], Any], *, samples: int = 5) -> list[float]:
    """Throughput medido por nível de "concorrência lógica" (lotes sequenciais)."""
    curva: list[float] = []
    for n in levels:
        ops = n
        t0 = time.perf_counter()
        for _ in range(samples):
            for _ in range(n):
                fn()
        dur = time.perf_counter() - t0
        curva.append((ops * samples) / dur if dur > 0 else math.inf)
    return curva

        }

"""Deploy declarativo, dados e simulador determinístico de rollback (M13 B17).

Invariantes:
- Deploy é descrito por um **documento declarativo** (versão + migrations +
  estratégia); o motor aplica exatamente o declarado, nunca improvisa.
- Rollback é determinístico: dado o estado e a release alvo, restaura o estado
  anterior aplicando as migrations ``down`` em ordem reversa; replay byte a byte.
- Release ruim é detectada por **health gate** (invariantes checáveis), não por
  opinião; release que não passa não entra e o rollback já está planejado.
- Kubernetes/cloud real: BLOCKED ambiental (sem cluster/credenciais). O motor
  aqui prova a semântica localmente; o documento declarativo é portável.
- Backup/restore: snapshot de dados local com hash; restore verifica integridade
  e declara RPO/RTO **medidos neste ambiente**, não metas de marketing.
"""

from __future__ import annotations

import copy
import hashlib
import json
from dataclasses import dataclass, field
from typing import Any


@dataclass(frozen=True)
class Migration:
    """Migration com ``up``/``down`` reversíveis sobre um dict de dados."""

    version: int
    name: str
    up: dict[str, Any]  # chaves adicionadas/atualizadas
    down_removes: tuple[str, ...]  # chaves removidas no rollback
    down_restores: dict[str, Any] = field(default_factory=dict)


@dataclass(frozen=True)
class Release:
    """Release declarativa: versão, migrations e saúde esperada."""

    tag: str
    migrations: tuple[Migration, ...]
    healthy: bool = True  # injeção determinística de "release ruim" no simulador
    strategy: str = "rolling"


@dataclass
class ClusterState:
    """Estado local simulado: dados + histórico de deploys (tudo verificável)."""

    data: dict[str, Any]
    schema_version: int = 0
    history: list[str] = field(default_factory=list)
    released: str = "none"


def hash_state(data: dict[str, Any]) -> str:
    """Hash canônico do estado dos dados (integridade de backup/restore)."""
    blob = json.dumps(data, sort_keys=True, separators=(",", ":")).encode()
    return hashlib.sha256(blob).hexdigest()


def backup(state: ClusterState) -> dict[str, Any]:
    """Snapshot imutável com hash; RPO local = este snapshot (ponto do backup)."""
    snapshot = copy.deepcopy(state.data)
    return {
        "schema_version": state.schema_version,
        "data": snapshot,
        "sha256": hash_state(snapshot),
    }


def restore(snapshot: dict[str, Any], state: ClusterState) -> None:
    """Restore determinístico: integridade obrigatória antes de qualquer escrita."""
    if hash_state(snapshot["data"]) != snapshot["sha256"]:
        raise ValueError("backup corrompido: hash diverge")
    state.data = copy.deepcopy(snapshot["data"])
    state.schema_version = int(snapshot["schema_version"])


class HealthGate:
    """Gate objetivo de saúde: release é recusada se a flag `healthy` for falsa.

    Em produção real isso seriam checks HTTP sintéticos e SLOs; aqui a decisão
    é determinística e registrada — o mecanismo (gate automático antes/depois do
    deploy) é o invariante sob teste.
    """

    def check(self, release: Release) -> list[str]:
        erros: list[str] = []
        if not release.healthy:
            erros.append(f"release {release.tag}: health check falhou")
        for m in release.migrations:
            if any(k in m.down_restores and k not in m.up for k in m.down_restores):
                erros.append(f"migration {m.version} restaura chave que não criou")
        return erros


def deploy(state: ClusterState, release: Release, gate: HealthGate) -> dict[str, Any]:
    """Aplica release se e somente se passar no gate; retorna o log do deploy."""
    erros = gate.check(release)
    if erros:
        return {"applied": False, "tag": release.tag, "reason": erros}
    for m in sorted(release.migrations, key=lambda x: x.version):
        if m.version <= state.schema_version:
            continue  # idempotente: migration já aplicada não reaplica
        state.data.update(m.up)
        state.schema_version = m.version
    state.released = release.tag
    state.history.append(f"deploy:{release.tag}")
    return {"applied": True, "tag": release.tag, "schema_version": state.schema_version}


def rollback(state: ClusterState, release: Release, target_schema: int) -> dict[str, Any]:
    """Reverte migrations da release até ``target_schema``; ordem reversa e total."""
    aplicadas = [m for m in release.migrations if target_schema < m.version <= state.schema_version]
    for m in sorted(aplicadas, key=lambda x: x.version, reverse=True):
        for chave in m.down_removes:
            state.data.pop(chave, None)
        state.data.update(m.down_restores)
        state.schema_version = min(state.schema_version, m.version - 1) if m.version > 0 else 0
    state.history.append(f"rollback:->{target_schema}")
    prev = state.history[-2] if len(state.history) >= 2 else "deploy:none"
    state.released = prev.removeprefix("deploy:")
    return {"rolled_back_to": target_schema, "schema_version": state.schema_version}


def release_design() -> dict[str, Any]:
    """Design declarativo canônico do Cartógrafo (portável a IAC real)."""
    return {
        "environments": ["staging", "production"],
        "strategy": "canary 10% -> 50% -> 100% com health gate entre etapas",
        "config": "12-factor: toda configuração por variável de ambiente",
        "secrets": "provedor de segredos; nunca no repositório nem em logs",
        "migrations": "expand-migrate-contract; down obrigatório e testado",
        "backup": "snapshot diário + antes de cada release; verificação por hash",
        "rollback": "release anterior + migrations down; RPO/RTO medidos no ambiente",
        "blocked": "Kubernetes/cloud real BLOCKED neste ambiente (sem credenciais)",
    }
Diagnóstico
  • migration sem down → rollback impossível por construção; down é obrigatório e testado;
  • redeploy que reaplica migration → estado deriva; idempotência por schema_version;
  • restore sem verificação de integridade → restaura lixo com confiança;
  • "health gate" manual → release ruim entra quando alguém está com pressa.

Checkpoint

  1. Por que expand-migrate-contract é a estratégia segura sob deploy contínuo?
  2. O que o hash do estado prova que "testes passaram" não prova?
  3. Como o design declarativo mudaria ao sair do simulador para Kubernetes real?

"""Production Readiness Review e game day com decisão go/no-go (M13 B18).

Invariantes:
- PRR é uma **matriz evidência-obrigatória**: cada item aponta para um arquivo
  de evidência existente (gate pytest/ruff/mypy ou doc). Item sem evidência
  não pode ser "aprovado"; a checagem é executável, não declarativa.
- Game day é determinístico: falha injetada, papéis, ações e timeline
  registrados em ordem; o postmortem é gerado da timeline, não reescrito.
- NO-GO é resultado legítimo e primeira classe: trilha de bloqueio explica
  causa e gera plano de desbloqueio automático.
"""

from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass, field
from pathlib import Path
from typing import TypedDict


@dataclass(frozen=True)
class PrrItem:
    area: str
    pergunta: str
    evidencia: str  # caminho relativo à raiz do módulo


PRR_CHECKLIST: tuple[PrrItem, ...] = (
    PrrItem("arquitetura", "componentes e contratos >= N3 com diagrama", "evidence/m13/B06"),
    PrrItem("dependências", "SBOM/licenças/pinagem revisados", "evidence/m13/B02"),

    PrrItem("acesso", "princípio de menor privilégio e revisão de contas", "evidence/m13/B12"),
    PrrItem("suporte", "Diátaxis + onboarding sem intervenção", "evidence/m13/B15"),
    PrrItem("rollback", "release ruim detectada e revertida em teste", "evidence/m13/B17"),
)


class PrrItemResult(TypedDict):
    area: str
    pergunta: str
    evidencia: str
    ok: bool


class PrrReport(TypedDict):
    total: int
    aprovados: int
    pendentes: int
    itens: list[PrrItemResult]
    go: bool


def prr_report(module_root: Path) -> PrrReport:
    """Avalia o PRR contra o disco: cada item precisa de evidência existente."""
    itens: list[PrrItemResult] = []
    for item in PRR_CHECKLIST:
        existe = (module_root / item.evidencia).exists()
        itens.append(
            {
                "area": item.area,
                "pergunta": item.pergunta,
                "evidencia": item.evidencia,
                "ok": existe,
            }
        )
    aprovados = sum(1 for i in itens if i["ok"])
    return {
        "total": len(itens),
        "aprovados": aprovados,
        "pendentes": len(itens) - aprovados,
        "itens": itens,
        "go": aprovados == len(itens),
    }

@dataclass
class GameDay:
    """Simulador determinístico de game day com falha injetada de verdade.

    A falha aqui é local (rollback de release ruim, B17). Os eventos são
    gerados pela execução real dos passos, não por um script de texto.

    timeline: list[Evento] = field(default_factory=list)

    def postmortem(self) -> dict[str, object]:
        """Postmortem derivado da timeline — impossível divergir dela."""
        inicio = self.timeline[0].t if self.timeline else 0

        return {
            "cenario": self.cenario,
            "duracao_min": fim - inicio,
            "eventos": [f"t+{e.t}min [{e.ator}] {e.descricao}" for e in self.timeline],
            "causa_raiz": "release ruim declarada; health gate falhou no canary",
            "acao_corretiva": "rollback automático via migrations down; canary<100%",
        }


def game_day_release_ruim(simulate: Callable[[], dict[str, object]]) -> GameDay:
    """Conduz o game day: injeta release ruim e executa o runbook de rollback.

    ``simulate`` é um callable ``() -> dict`` que executa o par deploy+rollback
    real do B17 e devolve o resultado observado.

    gd.registrar(0, "incident_commander", "declarado SEV-2 simulado; game day inicia")
    gd.registrar(2, "executor", "health gate reprovou release candidata")
    resultado = simulate()  # execução real, não narrativa
    gd.registrar(5, "executor", f"rollback executado: {resultado}")
    gd.registrar(7, "comunicador", "stakeholders informados: serviço estável em N-1")
    gd.registrar(10, "escriba", "timeline fechada; postmortem derivado")
    return gd

    veredito: str
    motivos: list[str]
    plano_desbloqueio: list[str]


def decide_go_no_go(prr: PrrReport, game_day: GameDay) -> GoNoGoDecision:
    """Decisão final: GO somente com PRR 100% evidenciado E game day concluído.

    NO-GO devolve o plano: lista dos itens pendentes e próximas ações — honesto.
    """
    pendencias = [i for i in prr["itens"] if not i["ok"]]
    timeline_ok = len(game_day.timeline) >= 5
    go = prr["go"] and timeline_ok and not pendencias
    return {
        "veredito": "GO" if go else "NO-GO",
        "motivos": [p["pergunta"] for p in pendencias] or ["PRR completo e game day concluído"],
        "plano_desbloqueio": [
            f"produzir evidência para '{p['area']}' e re-rodar PRR" for p in pendencias
        ],
    }

  • PRR por apresentação → slides decidem, não evidência; checar o disco;
  • game day sem injeção real → teatro; a falha tem que executar;
  • timeline reescrita → postmortem vira narrativa; derivar dos eventos;
  • "NO-GO impensável" → pressão iguala GO forçado; NO-GO com plano é entrega.

Invariantes:
- **BLOCKED ambiental e estruturalmente garantido**: sem sessão humana real
  registrada no `pilot_log`, nenhuma função devolve validação. O BLOCKED não

  assinalado antes de qualquer métrica; sem ele os dados são rejeitados.

- Hipótese rejeitada é resultado legítimo: a decisão inclui "rejeitar".

@dataclass(frozen=True)

    consentimento_texto: str

    tarefa_real: str

    produto_min: float  # medido com o produto
    erros_produto: int
    confianca_pos: int  # 1..5
    repetir: bool
    pagar: bool

            "n": n,
            "ganho_medio_min": round(delta, 2),
            "repetiriam": repetiriam,
            "pagariam": sum(1 for s in self.sessions if s.pagar),
            "hipotese": "apoiada" if delta > 0 and repetiriam >= n / 2 else "rejeitada",
        }

"""Lançamento, portfólio e defesa técnica com métricas rastreáveis (M13 B20).

Invariantes:
- Release versionada: o número de versão é derivado de ``git describe`` quando
  disponível, senão do ``__version__``; nunca hardcoded no dossier.
- **Toda métrica publicada aponta para evidência existente no disco** — a
  montagem do dossier falha se o caminho de evidência não existir.
- Dossier público não contém segredos, PII nem claims sem fonte; a checagem
  de "sem dados sensíveis" é um oráculo executável sobre o texto final.
- Demo script e perguntas da defesa foram curados com respostas que declaram
  explicitamente o que é BLOCKED e o que é medido.
"""

from __future__ import annotations

import re
import subprocess
from dataclasses import dataclass, field
from pathlib import Path


@dataclass(frozen=True)
class MetricRef:
    nome: str
    valor: str
    evidencia: str  # caminho relativo que precisa existir


@dataclass(frozen=True)
class ReleaseDossier:
    version: str
    changelog: tuple[str, ...]
    metricas: tuple[MetricRef, ...]
    limitacoes: tuple[str, ...]
    blocked: tuple[str, ...] = field(default_factory=tuple)

    def to_markdown(self) -> str:
        linhas = [f"# Cartógrafo {self.version}", "", "## Changelog", ""]
        linhas += [f"- {item}" for item in self.changelog]
        linhas += ["", "## Métricas (todas com evidência)", ""]
        linhas += [f"- **{m.nome}**: {m.valor} — evidência `{m.evidencia}`" for m in self.metricas]
        linhas += ["", "## Limitações conhecidas", ""]
        linhas += [f"- {item}" for item in self.limitacoes]
        if self.blocked:
            linhas += ["", "## Ambientalmente BLOCKED (honesto)", ""]
            linhas += [f"- {item}" for item in self.blocked]
        return "\n".join(linhas) + "\n"

def resolve_version(module_root: Path) -> str:
    """Versão de verdade: git describe; fallback para o version do pacote."""
    try:
        out = subprocess.run(
            ["git", "describe", "--tags", "--always", "--dirty"],
            cwd=module_root,
            capture_output=True,
            text=True,
            timeout=5,
            check=False,
        )
        if out.returncode == 0 and out.stdout.strip():
            return out.stdout.strip()
    except OSError, subprocess.SubprocessError:
        pass
    from capstone_lab import __version__

    return __version__


def build_dossier(
    module_root: Path,
    changelog: tuple[str, ...],
    metricas: tuple[MetricRef, ...],
    limitacoes: tuple[str, ...],
    blocked: tuple[str, ...],
) -> ReleaseDossier:
    """Monta o dossier verificando que toda evidência citada existe no disco."""
    faltantes = [m.evidencia for m in metricas if not (module_root / m.evidencia).exists()]
    if faltantes:
        raise ValueError(f"evidência ausente: {faltantes}")
    return ReleaseDossier(resolve_version(module_root), changelog, metricas, limitacoes, blocked)


def scan_public_text(text: str) -> list[str]:
    """Oráculo de "sem dados sensíveis" sobre o bruto final público."""
    problemas: list[str] = []
    for pattern in _SENSITIVE_PATTERNS:
        if pattern.search(text):
            problemas.append(f"padrão sensível encontrado: {pattern.pattern}")
    if "BLOCKED" in text and "honesto" not in text.lower() and "BLOCKED" in text:
        problemas.append("BLOCKED precisa ser rotulado honestamente")
    return problemas
