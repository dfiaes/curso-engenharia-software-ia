# M02A — Engenharia de Software Sênior em 2026

Estado: **G0 aprovado; G1 em produção**  
Carga: **30 horas**  
Linguagem canônica: **Python 3.14**

Este módulo atualiza fundamentos e prática de engenharia de software para um desenvolvedor experiente que está migrando de .NET/C# para Python e sistemas AI-native.

Ele será material de estudo completo no padrão visual e didático do M00: problema, modelo mental, decisão, implementação, falha, evidência, transferência, referências e avaliação por cenário.

## Decisão de linguagem

Python é a implementação normativa. .NET 10 aparece somente em um corte vertical comparativo para tornar diferenças reais visíveis; não há trilha paralela nem exigência de dominar .NET.

## Produto integrador

O laboratório `work-intake` será um monólito modular local de triagem assistida por IA. Política determinística decide; um `Advisor` agnóstico apenas recomenda. O laboratório é offline, reproduzível e não depende de provedor fechado.
