# Prompt: atualizar documentação (anti-drift)

```
Compare o diff desta branch (git diff origin/main...HEAD) com a documentação:
  docs/specs, docs/plans, docs/runbooks, docs/architecture.md, README, CHANGELOG, AGENTS.md.

1. Liste cada afirmação da doc que o diff tornou falsa, incompleta ou obsoleta (arquivo e trecho).
2. Liste comportamentos novos do diff que não estão documentados.
3. Proponha as edições exatas. Para decisões estruturais, rascunhe uma ADR.
4. Adicione entrada no CHANGELOG (Adicionado/Alterado/Corrigido/Removido) com a chave do ticket.
5. Se o agente (você) errou ou foi corrigido durante o trabalho, proponha uma linha para a seção
   "Armadilhas conhecidas" do AGENTS.md.
Não invente: se não puder verificar no código, marque como "precisa de confirmação humana".
```
