Currículo — Engenharia de Software e IA em Python

Uma trilha única, em cinco fases, do nível júnior ao nível de especialista e líder técnico em sistemas com IA. Python 3.14, material em português, labs executáveis sem conta paga.

Como usar. Siga as fases em ordem. Cada módulo abre com um diagnóstico rápido: se você acerta tudo, leia só a conclusão, faça o checkpoint e siga em frente. Quem já atua na área costuma passar rápido pela Fase 0 e parar exatamente nos pontos que a rotina deixou enferrujados. Comece pelo nivelamento para decidir onde entrar.

Trilha rápida. Se o objetivo imediato é trabalhar bem com agentes de código (Cursor, Codex, OpenCode, Claude Code ou um agente próprio) num projeto real, faça antes a Trilha rápida: o ciclo intenção → spec → plano → implementação → verificação → PR → esteira dev/cert/prod → operação, para projeto novo ou existente, com GitHub, Jira e Azure ou on-premise. Os modelos prontos estão no kit de arranque.

As cargas são estimativas para quem estuda o módulo inteiro e faz o lab. Estado de cada módulo: STATUS.md.

Capstone

O Cartógrafo atravessa o curso: cada fase acrescenta uma peça (contratos e dados, chamada ao modelo, avaliação, recuperação, agentes, segurança, operação). O M13 integra e defende o produto.

Fora do escopo

Pesquisa de fronteira (pré-treino de modelos grandes, RL profundo, robótica, infraestrutura GPU multinó) não faz parte do curso. ML tabular clássico aparece apenas no necessário dentro do M11.
