1. Decisão curricular

O M09 ensina protocolos como contratos entre processos: MCP (agente↔ferramenta/dado, com descoberta) e A2A (agente↔agente, com opacidade e ciclo de vida). Protocolo transforma N×M em N+M. O núcleo — registros, despacho, escopo do runtime, negação por capability, timeout, cancelamento e ciclo de vida de task — é implementado no laboratório sobre três transportes locais (memória, stdio com subprocesso real e HTTP em localhost via stdlib), sem dependência externa, conta ou rede pública. SDKs de fornecedor e hospedagem são trilha externa.

A integração no Capstone (mcp/, a2a/) só ocorre após spec própria. Versão de protocolo é dependência de produção: o material retrata a revisão vigente na data-base e manda confirmar antes de implementar.

3. Arquitetura do laboratório

núcleo (registros+despacho+escopo) ◄── transports ──► cliente A / cliente B
   │        memory (filas)                (implementações independentes)
   │        stdio (subprocesso real)
   │        http (localhost, stdlib)
   ▼
a2a (cards, tasks, polling) com opacidade entre pares

A referência fica em modulos/M09-protocolos-mcp-e-a2a/lab/. O roteiro Laboratório guiado M09, no final do HTML, cria cópia de trabalho em diretório temporário possuído pelo laboratório.
