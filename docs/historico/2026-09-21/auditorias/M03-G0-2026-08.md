# Auditoria G0 — M03 · FastAPI, PostgreSQL, Docker e CI

**Data:** 21/08/2026 · **Escopo:** definição de produção; nenhuma promoção de execução

## Constatações

1. O HTML legado contém oito blocos de temas relevantes, mas não possui laboratório versionado, rastreabilidade própria nem fontes por claim.
2. Sete práticas fragmentam a leitura. Há ainda tarefas que pedem conta e deploy externo dentro do percurso principal.
3. O módulo precisa de PostgreSQL e Docker reais para provar suas fronteiras. SQLite, mocks ou números de plano não podem substituir essa evidência.
4. O curso já possui o esqueleto `capstone/`, mas a alteração dele exige especificação própria. O laboratório M03 será isolado e só transfere convenções e evidências.

## Decisões

- produto de referência: `link-shortener`, em Python 3.14;
- prática obrigatória: local, em cópia temporária marcada, com PostgreSQL/Docker como pré-requisito explícito;
- deploy público: trilha opcional, sem credencial, conta ou serviço pago como requisito;
- adapters: FastAPI, SQLAlchemy, Alembic, Docker Compose, Testcontainers e GitHub Actions; os invariantes ficam documentados na especificação;
- cobertura: 32 cenários para HTTP, dados, arquitetura, container, integração, CI e operação local.
