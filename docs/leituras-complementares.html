Leituras complementares por fase

Fontes externas que aprofundam os módulos do currículo. Nada aqui é pré-requisito: cada módulo é autossuficiente. Use estas leituras para comparar com a fonte primária, consultar a referência completa ou seguir um assunto além do módulo. Documentação de produto, comandos, preços e limites mudam; confira a versão atual antes de aplicar uma configuração. A política de fontes está em POLITICA-FONTES-E-AGNOSTICISMO.md.

Fase 0 · Fundamentos

F01 · Terminal, sistema de arquivos, processos e Git

  • Pro Git (pt-BR) — Scott Chacon e Ben Straub: o livro oficial e gratuito de Git; referência para modelo de objetos, branches, rebase e recuperação.

F02 · Python do zero

  • Tutorial de Python 3.14 — Python Software Foundation: funções, módulos, estruturas de dados, exceções e arquivos, na semântica oficial.
  • Get started — pytest: primeiros testes, descoberta e execução local.
  • CS50's Introduction to Programming with Python — Harvard: aulas e exercícios para os pontos ainda novos.

F04 · Como a web funciona

  • Visão geral de HTTP — MDN Web Docs: cliente, servidor, requisição, resposta, headers e códigos de estado.
  • Learn OpenAPI — OpenAPI Initiative: descrição e validação de contratos HTTP, sem confundir contrato com implementação.

F05 · Bancos relacionais, SQL e modelagem

  • Use The Index, Luke — Markus Winand: como índices funcionam e como escrever SQL que os usa.

Fase 1 · Engenharia de software

S01 · Design de código

  • Refactoring — Martin Fowler: página do livro de referência em refatoração; o catálogo de refatorações está no site do autor.
  • Refactoring.Guru — refatoração e padrões: catálogo ilustrado de code smells e técnicas.

M03 · Serviço real: FastAPI, PostgreSQL, Docker e CI

  • Tutorial do FastAPI: validação, erros e testes para um serviço Python local.
  • Tutorial do PostgreSQL: relações, consultas e transações.
  • The Twelve-Factor App: princípios de configuração, processos e logs para serviços implantáveis.

Fase 2 · AI Engineering

M00 · Trabalhar com agentes de programação

  • Codex Prompting Guide — OpenAI Cookbook: padrões de tarefa, contexto e verificação no Codex; comandos e modelos são específicos do produto.
  • Best practices for Claude Code — Anthropic: exploração, planejamento, implementação e verificação, mais contexto, permissões e sandbox no Claude Code.
  • Run long horizon tasks with Codex — OpenAI Developers: tarefas longas; separe princípios transferíveis de recursos do produto.
  • Agents — OpenCode: agentes primários e subagentes como exemplo de harness.

M01 · Desenvolvimento orientado a especificação e execução paralela

  • Config basics — OpenAI Codex: configuração pessoal e do projeto, precedência, modelo, esforço, aprovações e sandbox.
  • Rules — OpenCode: AGENTS.md, inicialização e precedência de instruções.
  • Customize Cursor — Cursor: regras, Skills, MCP, subagentes, hooks e seus escopos.
  • Skills — OpenAI Developers: Skill como workflow reutilizável e sua fronteira com MCP.
  • Agent Skills — OpenCode: SKILL.md, descoberta, frontmatter e permissões.

M05 · LLM na prática

  • Prompting — OpenAI Developers: instruções, parâmetros tipados, prompts versionados e testes; o endpoint é específico da OpenAI.
  • Using tools — OpenAI Developers: contrato de tool calling e responsabilidade da aplicação pela validação e execução.
  • Prompt engineering overview — Anthropic: orientação do fornecedor; mantenha invariantes separados de parâmetros proprietários.

M06 · Evals e observabilidade

  • Demystifying evals for AI agents — Anthropic Engineering: tarefa, execução, grader e taxa de sucesso (orientação de praticante).
  • Evals — OpenAI Developers: abordagem da plataforma OpenAI, para comparar com avaliações agnósticas no código.
  • OpenTelemetry Python — Get started: spans, traces, métricas e instrumentação.

M07 · RAG de verdade

  • Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks — NeurIPS 2020: o paper original de RAG.
  • Contextual Retrieval — Anthropic Engineering: estudo de caso de praticante; verifique método e limites antes de interpretar os ganhos.

M08 · Agentes e context engineering

  • Building effective agents — Anthropic Engineering: workflows versus agentes e seus trade-offs (não é padrão normativo).
  • Effective context engineering for AI agents — Anthropic Engineering: organização de contexto, ferramentas, dados e histórico.
  • Agents — OpenAI Developers: runtime gerenciado, harness próprio e loop da aplicação; APIs específicas da plataforma.

M09 · Protocolos: MCP na prática

  • Especificação do Model Context Protocol: arquitetura, recursos, prompts, ferramentas, consentimento e segurança.
  • Get started — MCP Python SDK: servidor Python mínimo.
  • MCP servers — OpenCode: configuração de servidores locais ou remotos, custo de contexto e credenciais.
  • Docs MCP em Codex, Cursor e Claude Code — OpenAI Developers: instalação de um servidor MCP de documentação em vários clientes.
