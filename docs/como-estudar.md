# Estudo no seu ritmo

Não há uma forma obrigatória de estudar este curso. Você pode ler ou praticar com o tempo disponível, pausar e voltar ao mesmo ponto. Os blocos organizam assuntos; não exigem sessões de duas horas.

Use o [currículo](../CURRICULO.md) para localizar o assunto e o [status do material](STATUS-IMPLEMENTACAO-CURSO.md) para saber o que já foi verificado. Nos módulos, o sumário permite retomar a leitura; a prática guiada fica reunida no final e o checkpoint é separado.

Anotar uma dúvida, reler uma explicação, consultar código e pedir ajuda são possibilidades, não etapas obrigatórias. Diário, commit, revisão, aquecimento e avaliação não são condições para sentar e estudar ou para encerrar uma sessão.

Este endereço foi mantido porque o histórico pessoal de estudo contém links para ele. A navegação principal está no [README](../README.md).
