# Badge

Etiqueta curta (uma ou duas palavras) ao lado de um título ou controle.

**Tons:** `neutral` (duração, contagem: "12′", "1/2"), `brand` (estado positivo: "Concluída"), `ink` (dica que aponta para uma ação: "clique aqui"), `highlight` (novidade; use raramente).

**O consumidor fornece:** `children` e `tone`. Nunca use a cor como única informação — o texto já diz o estado.
